# 这个实验到底在干什么（大白话版）

这份文件不讲代码怎么写，只讲**怎么理解**：每个名词是什么、代码里的每一行对应什么概念、
结果图怎么看、老师问起来怎么答。

---

## 一、一句话说清楚这个实验

给电脑看 6 万张小图片（32×32 像素），让它自己学会认 10 类东西：
飞机、汽车、鸟、猫、鹿、狗、青蛙、马、船、卡车。

学完之后，随便给它一张**没见过**的图，它能说出这是哪一类，并给出把握程度。

就这么简单。剩下的所有术语（卷积、反向传播、学习率……）都只是"怎么让它学会"的细节。

---

## 二、先把名词一个个讲明白

### 1. 图像分类
输入一张图，输出一个类别。程序里图片是一个张量，形状 `3×32×32`，
三个 3 分别是 RGB 三个颜色通道，32×32 是长和宽。

### 2. 为什么要把数据分成三份

这是整个实验里最重要的概念，用考试打比方：

| 集合 | 打比方 | 在我们项目里 | 用途 |
| --- | --- | --- | --- |
| 训练集 | 课本例题 | 20000 张 | 用来学习参数（调权重） |
| 验证集 | 模拟考 | 10000 张 | 用来挑模型、看有没有学过头 |
| 测试集 | 期末考 | 10000 张（官方） | 最后只考一次，代表真实水平 |

**为什么不能只有训练集和测试集？**
因为训练过程中你要做很多选择：学几轮、学习率多大、哪个模型最好。
如果拿测试集来做这些选择，就等于提前看过期末考卷再上考场，最后的分数是假的。
这就是老师要求的"三个集合必须相互独立"，也叫做**不能有数据泄漏**。

### 3. 卷积（Convolution）

拿一个小窗口（我们用的是 3×3）在图片上从左到右、从上到下滑动，
每滑到一个位置，就把窗口盖住的 9 个像素按权重加起来，得到一个数。

滑完一整张图，就得到一张"新的图"，里面记录的是**局部特征**：
边缘在哪、颜色怎么变、有没有条纹。

多个卷积核 = 多种特征探测器。我们的模型第 1 层用 32 个核，
就是同时找 32 种不同的低级特征。

`padding=1` 的意思是：在图片外围补一圈 0，这样做完卷积图还是一样的宽高（32×32 不会变小）。

### 4. ReLU（激活函数）
把所有负数变成 0，正数不变。为什么要它？
没有它的话，多层卷积叠起来在数学上等价于一层线性变换，网络再深也没用。
有了非线性，网络才能拟合复杂的规律。

### 5. 池化（Pooling）
把 2×2 的小块里取最大值，图的长宽各缩小一半。
作用：保留最明显的特征、减少计算量、让模型对小范围位移不那么敏感。

我们用了两次池化：`32×32 → 16×16 → 8×8`。

### 6. 全连接层（Fully Connected）
把最后得到的 64×8×8 个特征值拉平成一串，接一个 256 维的隐藏层，
最后输出 **10 个数字**，分别对应 10 个类别的"打分"（叫 logits）。

哪个分数最高，就判成哪一类。

### 7. Loss（损失）
衡量"预测和真实差多少"。分类任务用交叉熵（`nn.CrossEntropyLoss`）。
Loss 越小说明预测越准。训练的目标就是**把 Loss 降下来**。

### 8. 反向传播（`loss.backward()`）
PyTorch 会自动算出：**每个参数应该往哪个方向调、调多少，才能让 Loss 变小**。
算出来的东西叫梯度。

你不用手推导数，这是 PyTorch 最大的价值。

### 9. 优化器（`optimizer.step()`）
拿着梯度去改参数：

```
新参数 = 老参数 - 学习率 × 梯度
```

沿着梯度的**反方向**走一小步，Loss 就会小一点。走很多很多步，模型就学会了。

学习率就是"步子大小"：太小走得太慢，太大一步跨过最低点直接翻车（这就是实验 6 的内容）。

### 10. batch 和 epoch

- **batch（批）**：一次喂给模型多少张图。我们用 128。
  为什么不一次喂 20000 张？显存放不下，而且一批一批更新反而收敛更快更稳。
- **epoch（轮）**：把整个训练集完整过一遍叫一轮。我们训练了 25 轮。

### 11. 过拟合
模型把训练集"背下来"了：训练集准确率很高，验证集/测试集却很差。
这次实验**没有出现**这种情况（两条曲线离得很近）。

## 三、我们的模型长什么样

```
输入图片 3×32×32
        ↓
卷积块 1：Conv(3→32) → BN → ReLU → Conv(32→32) → BN → ReLU → 池化
        ↓ 变成 32×16×16
卷积块 2：Conv(32→64) → BN → ReLU → Conv(64→64) → BN → ReLU → 池化
        ↓ 变成 64×8×8
展平 → 全连接 256 → ReLU → Dropout(0.3) → 全连接 10
        ↓
   10 个类别的分数
```

**BN（BatchNorm）**：把每层输出的数值范围拉回正常区间，训练更稳、收敛更快。
**Dropout(0.3)**：训练时随机"掐掉"30% 的神经元，防止模型过度依赖某几个特征，是一种防过拟合手段。

整个模型只有 **111 万个参数**，属于入门级的小网络，所以在你自己的笔记本（RTX 3050）上
训练 25 轮只要 4 分钟。

## 四、代码是怎么组织的（文件地图）

| 文件 | 负责什么 | 关键函数 |
| --- | --- | --- |
| `config.py` | 所有路径和超参数都放这里，改参数只改这一个文件 | `_resolve_dir()` |
| `dataset.py` | 数据准备：解压原始数据、解析 pickle、统计类别分布、划分数据集、预处理 | `load_batch()`、`make_splits()`、`build_transform()`、`CIFARDataset` |
| `model.py` | 网络结构 | `conv_block()`、`SimpleCNN` |
| `train.py` | 训练 + 验证循环，保存最佳模型，画曲线 | `train_one_epoch()`、`evaluate()`、`train()` |
| `evaluate.py` | 测试集评估：准确率、混淆矩阵、每类指标 | `confusion_matrix()`、`per_class_metrics()` |
| `predict.py` | 单张图片预测 | `predict_tensor()` |
| `visualize.py` | 把多张预测结果画成一张大图 | `predict_batch()` |

### 训练的核心就这 5 行

`train.py` 里 `train_one_epoch()` 的循环体，是整个实验的心脏：

```python
outputs = model(images)              # 1. 前向传播：算预测
loss = criterion(outputs, labels)    # 2. 算损失：错得有多离谱
optimizer.zero_grad()                # 3. 清空上一轮的梯度
loss.backward()                      # 4. 反向传播：算每个参数的梯度
optimizer.step()                     # 5. 更新参数：沿着正确的方向挪一小步
```

训练就是把这 5 行重复 `25 × 157` 次（157 是一轮的批次数）。

> 为什么第 3 步要清梯度？因为 PyTorch 的梯度默认是**累加**的，
> 不清零就会把上一批的梯度也加进来，参数更新就乱了。

## 五、结果图怎么看

### 1. 训练曲线（`训练曲线_Loss与准确率.png`）

- **左图看 Loss**：两条线都在往下走，说明模型一直在学。
- **右图看准确率**：两条线都在往上走，第 25 轮时验证集到 78% 左右。
- **两条线的距离**：离得越近越健康。这次两条线几乎贴在一起，说明**没有过拟合**。
- **一个反直觉的现象**：验证集准确率（78.36%）比训练集（约 76%）还高。
  这不是 bug —— 训练集做了随机裁剪和翻转，等于一直在做"更难的题"；
  验证集是不增强的干净图片，所以分数反而高。
  **判断过拟合要看"训练远高于验证"，而不是"两者谁高"。**

### 2. 混淆矩阵（`测试集混淆矩阵.png`）

横轴是模型预测的类别，纵轴是真实类别，每一格是**这一类的图片被预测成各类的比例**。

- **对角线**（左上到右下）是预测正确的比例，颜色越深越好。
- **非对角线的亮格**就是模型的"软肋"。我们最亮的两格是
  `猫→狗 0.17` 和 `狗→猫 0.15`——猫和狗长得本来就像，32×32 分辨率下连人都不一定分得清。
- 汽车、船、卡车这几行几乎是纯深蓝（0.88~0.91），说明模型对它们很有把握。

### 3. 三个指标怎么理解（以"猫"为例）

假设 1000 张真猫的图，模型说其中 580 张是猫，另外还错报了 354 张别的图是猫：

| 指标 | 算法 | 大白话 | 我们这次（猫） |
| --- | --- | --- | --- |
| 精确率 Precision | 580 / (580+354) | 模型说是猫的里面，有多少真是猫（别乱报） | 62.10% |
| 召回率 Recall | 580 / 1000 | 真猫里面，被找出来多少（别漏报） | 58.00% |
| F1 | 两者的调和平均 | 综合分，防止只看一个指标偏科 | 59.98% |

**宏平均 F1** 是十类 F1 的平均值（77.82%），用来看各类别表现是否均衡。
我们这次准确率 77.91%、宏平均 F1 77.82%，两数接近，说明没有哪一类被彻底放弃。

### 4. 预测可视化（`预测结果可视化_random.png`）

标题绿色=预测正确，红色=预测错误。看那些红色样本你会有一个直观感受：
它们本身就很模糊、姿态奇怪、或者主体只占一小块——**模型错得并不冤**。

## 六、老师可能问什么（附标准答案）

**1. 为什么必须有验证集？直接用测试集调参不行吗？**
不行。测试集代表"最终考试"，只能考一次。如果用测试集反复调参，模型就间接记住了测试集，
最后的准确率会虚高，不能反映真实水平。这叫数据泄漏。

**2. 为什么测试集准确率 77.91% 比验证集 78.36% 略低？**
正常波动。两批数据是独立的，1 万张样本上差 0.45% 完全在统计误差范围内，
而且测试集是模型完全没见过的数据，略低很自然。

**3. 为什么验证集准确率比训练集还高？不是应该训练集更高吗？**
因为训练集做了数据增强（随机裁剪 + 水平翻转），难度更大；
验证集是原始图片、不增强。所以训练集分数低一点很正常。
如果反过来出现"训练 95%、验证 70%"这种差距，那才是过拟合。

**4. 归一化的均值和标准差是怎么来的？为什么用这两个固定数字？**
用的是 CIFAR-10 官方公布的**训练集**统计值（0.4914/0.4822/0.4465 和 0.2470/0.2435/0.2616）。
必须用训练集的统计量，如果用验证集或测试集去算，就属于数据泄漏。

**5. 数据增强算不算作弊？**
不算。增强只作用在训练集上（随机裁剪、翻转），而且都是在合理范围内变换，
相当于"多做了几道类似的练习题"。验证集和测试集一律不做增强，保证评估公平。

**6. padding=1 是干什么的？**
在图片外围补一圈 0，让 3×3 卷积之后图的长宽不变。
如果不补，每卷积一次图就会缩小 2 个像素，浅层网络很快就缩没了。

**7. 为什么要 BatchNorm 和 Dropout？**
BN 让每层输出分布稳定，训练更快更稳；Dropout 训练时随机丢一部分神经元，
逼迫网络不依赖个别特征，能缓解过拟合。我们的 Dropout 比例是 0.3。

**8. 为什么不用 ResNet / Transformer / YOLO？**
本实验的目标是理解流程，不是刷分。简单 CNN 只有 111 万参数，
能在几分钟内跑完，便于观察每一步的作用。YOLO 是做目标检测的，不是分类任务。

**9. 如果要把准确率再提高 10 个点，你会怎么做？**
按性价比排序：① 用满官方 50000 张训练数据；② 加更强的数据增强（Cutout、Mixup、RandAugment）；
③ 训练更多轮 + 学习率预热与余弦退火；④ 换更深的网络（ResNet-18 级别）；
⑤ 加上测试时增强（TTA）。前两条改动最小、收益最大。

**10. 训练时 Loss 一直不降怎么办？**
先查学习率是不是太小，再查有没有漏写 `optimizer.step()`（只 backward 不更新，参数永远不动）、
有没有漏写 `optimizer.zero_grad()`（梯度累加会乱）。这三个是最常见的原因。

## 七、自己动手验证理解（推荐做两个）

改 `config.py` 里的一个数字，重新跑一遍，观察结果变化，比看十遍讲解都管用：

| 想验证什么 | 怎么改 | 预期现象 |
| --- | --- | --- |
| 数据量有多重要 | `TRAIN_PER_CLASS` 从 2000 改成 500 | 测试准确率明显下降（大概掉到 60% 出头） |
| 数据增强有没有用 | 把 `dataset.py` 里 `build_transform` 的两个增强注释掉 | 训练集准确率会立刻高于验证集，差距变大 |
| 学习率的影响 | `python train.py --lr 0.1` | Loss 曲线剧烈震荡，甚至发散 |
| batch size 的影响 | `python train.py --batch-size 32` | 每轮更慢，但曲线可能更抖 |
| 模型预测有多依赖上下文 | `python predict.py --image 你自己的图` | 32×32 下分辨率很低，别期待太高 |

改完记得把数字改回去，或者把改动写进实验报告的"对比实验"部分——这属于加分内容。

## 八、最后：整个流程背下来就够了

```
① 数据准备：下载 → 解析 → 统计类别分布 → 划分训练/验证/测试 → 预处理
② 搭模型  ：卷积 + ReLU + 池化，重复两次，再全连接输出 10 类
③ 训练    ：前向 → 算 Loss → zero_grad → backward → step，重复很多轮
④ 选模型  ：每一轮在验证集上看效果，保存验证集上最好的那一版
⑤ 评估    ：用测试集算准确率、混淆矩阵、每类的精确率/召回率/F1
⑥ 预测    ：拿一张新图，输出 Top-3 类别和概率
⑦ 展示    ：把预测结果画成图，绿色对、红色错
```

这七步是所有深度学习项目的通用套路。
以后换成目标检测、图像分割、文本分类，变的只是第 ② 步的网络结构和第 ① 步的数据，
**③④⑤⑥ 的骨架几乎一模一样**。理解了这个实验，你就理解了深度学习的标准工作流。
